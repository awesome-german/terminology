## 用語データベース

*包括的な多言語用語データベースと管理システム*

- [IATE (InterActive Terminology for Europe)](https://iate.europa.eu/) - 24言語で800万以上の用語を含むEUの多言語用語データベース（ドイツ語を含む）。
- [Linguee](https://www.linguee.com/german-english) - 実際の文書からのコンテキスト例を含むバイリンガル辞書と翻訳検索エンジン。
- [TERMDAT](https://www.termdat.bk.admin.ch/) - スイス連邦行政の用語データベース（ドイツ語、フランス語、イタリア語、ロマンシュ語、英語）。
- [TERMiTRADE](https://www.termitrade.eu/) - 国際貿易とビジネスのための多言語用語データベース。
- [EuroTermBank](http://www.eurotermbank.com/) - ドイツ語技術用語を含むヨーロッパ言語の用語バンク。
- [DANTERM](https://www.cc.au.dk/danterm/) - ドイツ語-デンマーク語用語リソースを持つデンマーク用語センター。
- [WIPO Pearl](https://www.wipo.int/reference/en/wipopearl/) - 特許と知的財産用語のWIPO多言語用語ポータル。
- [ELEXIS](https://elex.is/) - ドイツ語用語リソースを持つヨーロッパ辞書編纂インフラストラクチャ。
- [TERMit](https://termit.pugetsound.edu/) - 広範なドイツ語技術用語を持つ学術用語データベース。
- [TermCoord](https://termcoord.eu/) - 欧州議会の用語調整ユニットリソースとツール。
- [BeoLingus](https://dict.tu-chemnitz.de/) - 45万以上のエントリを持つケムニッツ工科大学のドイツ語-英語辞書。
- [LISA Terminology Exchange](https://www.ttt.org/) - ドイツ語を含むグローバリゼーションとローカリゼーション用語リソース。
- [Microsoft Language Portal](https://www.microsoft.com/en-us/language) - ドイツ語でのソフトウェアローカリゼーションのためのMicrosoft用語検索。
- [SAP Terminology](https://help.sap.com/docs/) - ドイツ語でのエンタープライズソフトウェアのためのSAP技術用語データベース。
- [UN Terminology](https://unterm.un.org/) - ドイツ語を含む国連の多言語用語データベース。
- [FAO Terminology](http://www.fao.org/faoterm/) - 国連食糧農業機関の多言語用語ポータル。
- [WHO Terminology](https://www.who.int/health-topics/) - 世界保健機関の健康用語リソース。
- [IBM Terminology](https://www.ibm.com/docs/en) - ドイツ語でのIBMの技術文書と用語。
- [Google Developer Documentation Style Guide](https://developers.google.com/style) - テクニカルライティングと用語標準。
- [Termium Plus](https://www.btb.termiumplus.gc.ca/) - カナダ政府の用語と言語データバンク。

## 貢献

貢献を歓迎します！最初に[貢献ガイドライン](CONTRIBUTING.md)をお読みください。

貢献するには：

1. このリポジトリをフォーク
2. 追加のための新しいブランチを作成
3. 適切なカテゴリにリソースを追加
4. エントリが次の形式に従っていることを確認：`[リソース名](URL) - 簡単な説明。`
5. テキストエディタが末尾の空白を削除するように設定されていることを確認
6. プルリクエストを送信

プルリクエストが次のガイドラインに従っていることを確認してください：

- 新しい提案を行う前に、重複を避けるために以前の提案を検索
- 提案ごとに個別のプルリクエストを作成
- 次の形式を使用：`[リソース名](リンク) - 説明。`
- 新しいカテゴリまたは既存の分類の改善を歓迎
- 説明を短く簡潔に、しかし説明的に保つ
- 大文字で説明を開始し、ピリオドで終了
- スペルと文法を確認
- テキストエディタが末尾の空白を削除するように設定されていることを確認
- プルリクエストには有用なタイトルがあり、リソースへのリンクと含まれるべき理由を含む

ご貢献ありがとうございます！
